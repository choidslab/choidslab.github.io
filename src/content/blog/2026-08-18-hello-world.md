For the past year this site ran on a Jekyll academic theme. It worked, but it was never really *mine* — hundreds of files I didn't write, features I didn't use, and a design I couldn't fully control.

So I rebuilt it from scratch with [Astro](https://astro.build). The goals were simple:

- **Light.** The site ships almost no JavaScript — just a theme toggle and a mobile menu.
- **Easy to run.** Writing a post means dropping a Markdown file into a folder and pushing to GitHub. No admin panel, no database, no server.
- **Ready to grow.** The site is structured like a research lab homepage (Research / Publications / News), so when the time comes, it can grow from a personal page into a lab site by editing a single config file.

The design language is deep blue — the color I use across my research documents — with a royal-red accent, in both light and dark mode.
